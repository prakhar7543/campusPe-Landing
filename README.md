# CampusPe Landing Page

A responsive landing page built as part of a frontend development assignment for **CampusPe**. The goal is to recreate the provided Figma design as closely as possible using Next.js, React, HTML, CSS, and JavaScript.

## 📌 Project Overview

CampusPe is a platform designed to connect students, colleges, and employers in one place. The landing page showcases its major features, including opportunity discovery, resume uploads, college recruitment, employer hiring, and mobile app experiences.

This project focuses on building a modern, responsive, and interactive user interface that follows the supplied design reference.

## ✨ Features

- **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screen sizes.
- **Modern Hero Section:** Highlights CampusPe's core value proposition and provides clear calls to action.
- **Opportunity Discovery:** Displays example job and internship opportunities.
- **Resume Upload Interface:** Provides a file-selection interface with supported-format guidance.
- **College Features:** Highlights college profiles, student connections, campus recruitment, and placement tracking.
- **Employer Features:** Showcases job posting, candidate matching, interview coordination, and hiring workflows.
- **App Showcase:** Presents the mobile application interface and download section.
- **Interactive UI:** Includes button hover states, focus states, navigation links, and subtle visual effects.
- **Reusable Components:** Uses React components to keep the code organized and maintainable.

## 🛠️ Tech Stack

- **Next.js** — React framework
- **React** — Component-based UI development
- **JavaScript (JSX)** — Application logic and component rendering
- **HTML5** — Page structure
- **CSS3** — Styling, responsive layouts, gradients, and animations
- **Git & GitHub** — Version control and source code hosting

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Navigate to the project directory

```bash
cd campuspe-landing
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```

The page will be available locally. Changes made to the source files will appear in the browser during development.
